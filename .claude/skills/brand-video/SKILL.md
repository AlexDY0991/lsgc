# 品牌视频制作规则

这份规则来自 CoolFly 品牌片项目十几轮返工的教训。每次开工前通读一遍，**不要凭记忆**；再读 `BRAND.md`（品牌规则）、`HANDOFF.md`（当前进度）、`ASSETS.md`（资产清单）。

## 一、分工
- **用户只做决策和评判：** 选方向，确认资产、分镜、动态分镜和成片。
- **Claude 做中间的全部工作：** 找参考和拉片、写脚本和提示词、生成、检查、剪辑、声音、质检、交付。
- 用中文交流。画面文字的语言按 BRAND.md 的规定。
- 每完成一步就 commit 并 push。交付物用 SendUserFile 发，附简短中文说明：改了什么、花了多少积分、需要用户决定什么。

## 二、好片子的标准（用户在 CoolFly 项目里反复强调）
1. **节奏、画面、视觉冲击、代入感优先。** 一分钟的片子不追求强故事。
2. **商业大片感：**
   - 快慢对比强：长镜头蓄势，突然抽空（真空），然后炸开；
   - 每个镜头都写明运镜；
   - 转场要有动机：匹配切、前景遮挡、甩镜、越过边缘的展开、切在动作上，不用生硬的直切。
3. **场景要有变化，画面要"动起来"。** 单一场景很快就会显得平。
4. **人物要真实：** 皮肤有质感，表演自然，不要 AI 感。
5. **一致性：** 人物、服装、产品结构、道具位置、光线方向、运动方向前后都要对得上。
6. **节奏标杆：** CoolFly 的元际片 60 秒 44 个镜头，中位镜头长 1.25 秒，**没有一个镜头重复**。

## 三、制作流程和确认关口
**不能跳步骤。** 每个"✅ 用户确认"之前，不进入下一步。

### 第 0 步 · 简报与参考
- 读 BRAND.md、ASSETS.md、`docs/higgsfield-realism-workflow-notes.md`（Higgsfield「3-Step Workflow」笔记，必读）。
- 拉参考片：先 `bash tools/setup.sh`，再运行 `$STUDIO_TOOLS/venv/bin/python tools/ref_analyze.py 参考片.mp4 输出目录/`。它输出镜头表、节奏统计、缩略图和运镜初判，运镜初判只能当提示，要结合缩略图看。
  - 云端下载不了 YouTube 和 Vimeo，不要尝试绕过。请用户自己下载 480p 版本，传到画布或仓库。
- 出 3–8 个创意方向。每个写清：一句话、洞察、怎么展开、冲击力和代入感从哪里来、一致性风险，并给出推荐。
- 从**品牌**（这条片在品牌叙事里承担什么）和**受众**（目标人群最大的心理门槛是什么）两个角度论证。
- ✅ **用户选方向。**

### 第 1 步 · 资产：先做资产，逐个确认（Higgsfield 第一步）
1. **产品 / 道具图：**
   - 有 3D 模型就用模型渲染（three.js 无头渲染）；
   - 再加上真实产品照和白底图，拼成三视图：正面、侧面、3/4、背面，以及关键细节（例如操作方式、手持方式）。
   - ✅ **用户确认。**
2. **人物定妆：** 每个角色一张三联定妆照（16:9）：
   - 左：正面头肩，人脸只出现在这一格；
   - 中：正面全身，从脖子以下裁切；
   - 右：背面全身，和中间同比例、同地平线；
   - 中灰无缝背景、柔光、真实皮肤毛孔，不磨皮、不美化。
   - 人物和产品有互动的（坐、握、穿、用），另出一张互动定妆照。
   - ✅ **用户确认。**
3. **场景布局图：** 每个地点一张，按动作设计布局：
   - 3/4 视角，前景、中景、背景分明；
   - 写死光线方向、地标、人和产品的位置、运动路线、机位；
   - 复杂站位另画一张俯视示意图，用百分比坐标标位置。
   - ✅ **用户确认。**
4. 确认后的资产登记进 ASSETS.md（文件路径、画布节点 ID、用途、确认状态）。

### 第 2 步 · 连贯性设定 + 分镜
- **连贯性设定（continuity bible）：** 光线方向、运动方向（例如全程从左往右）、服装、道具位置、时间推进。每条提示词都原样附上。
- 分镜图每个镜头一张，**只能引用已确认的资产**，提示词里用 `@资产名` 引用。
- 画完逐张对照连贯性设定检查，不合格的先重画，再给用户：
  - 手和道具的位置（左右）；
  - 服装、发型；
  - 产品结构；
  - 光线方向、运动方向；
  - 场景对不对；
  - 有没有混进别的参考图里的元素。
- ✅ **用户确认分镜。**

### 第 3 步 · 动态分镜（animatic）
- 正常商业片的流程：先把分镜图卡临时配乐剪成会动的样片，判断节奏和叙事，再花钱拍摄。
- 做法：静态图加推拉摇移，标出分镜号和时间，长度和成片一样。参考 `tools/animatic_example.py`。
- 临时配乐：用 higgsfield-motion skill 的 `score.html` 代码合成，节奏点（drop、vac、lift、end）按镜头表精确设置；也可以用用户提供的参考曲（只在内部用）。
- 质检：节奏点误差在一帧以内，−14 LUFS，真峰值 ≤ −1 dBTP。
- ✅ **用户确认节奏和叙事。** 这一步不花视频积分。

### 第 4 步 · 生成视频（Higgsfield 第二步）
- **一次生成就是一场完整的戏（约 15 秒）**，镜头内的运镜和转场写进提示词。结构按 `higgsfield-timed-prompts` skill：一句话总述、CAST、道具规则、各地点布局、LOOK、带时间码的 SHOTS、SOUND、CONTINUITY。
- 每条提示词都完整重复人物、服装、产品规则，不依赖上一条。
- 场与场之间：用上一场的最后一帧作为下一场的首帧，或者用动作驱动的匹配切。
- 即梦相关做法（预设运镜、参考视频、样片模式）见 `jimeng-canvas` skill。
- 先跑一场测试，逐帧检查合格后再跑其余各场。每次先报价，✅ **用户确认后才运行。**

### 第 5 步 · 剪辑
- 剪辑脚本参考 `tools/build_cut_example.py`。镜头表格式：`(开始, 结束, 素材, 入点, 速度, 内容标签)`。
- **出片前必须通过 `tools/edl_check.check(SHOTS, DUR)`**：同一段画面不能用两次，同一内容只出现一次，相邻镜头不能来自同一段素材，镜头不短于 0.4 秒。
- 节奏点卡音乐的真实重拍，用 higgsfield-motion 的 `music_window.py --hits/--sections` 测。对不上时移动音乐，不移动画面。
- 快切只放在高潮处，每次 3–4 刀，每刀来自不同素材。高潮之前留真空：近乎静音、慢动作。
- 渲染后出逐镜头缩略图自查：重复、衔接（方向、光线、服装）、瑕疵、字幕、logo 位置。
- ✅ **用户定剪。**

### 第 6 步 · 音乐、声音、终版
- 最终音乐：定剪后用正版授权曲（Artlist、Musicbed 等允许剪辑的曲库，由用户购买），由 Claude 按画面剪辑。
  - AI 生成的音乐（即梦 Seed Music）不按提示词里的时间点走，强弱对比也弱，最多只能当草稿。
- 音效；临时配音用 `tools/vo.py`（Kokoro，带 Whisper 回听逐字校对），正式版换专业配音。
- 混音：配音时把音乐压低（ducking），但压低的音乐不能在重拍前 0.6 秒内恢复，否则听起来像重拍提前了。片段自带的声音淡入 20 毫秒、淡出 150 毫秒。两遍响度标准化到 −14 LUFS，加限幅器，真峰值 ≤ −1 dBTP。
- 高清：只把定剪用到的镜头直出 1080p（由用户在即梦网页上操作），替换素材后重新合成。
- 再出 30 秒、15 秒版本和竖版（需要的话）。

## 四、检查清单（每次交付前逐项过）
- [ ] 产品结构和资产一致；人物的握持、操作方式和左右与互动定妆照一致
- [ ] 服装和发型与定妆照一致，没有混进别的参考图的元素
- [ ] 光线方向、运动方向与连贯性设定一致
- [ ] BRAND.md 里的禁忌和安全规则都满足
- [ ] 没有重复镜头，edl_check 通过
- [ ] 节奏点误差在一帧以内，−14 LUFS，≤ −1 dBTP，时长准确
- [ ] 字幕清楚，logo 不压人头，画面文字的语言按 BRAND.md

## 五、工具
| 工具 | 用途 |
|---|---|
| `tools/setup.sh` | 新容器的工具环境（装在 `/tmp/studio-tools`）：yt-dlp、场景检测、OpenCV、Kokoro、Whisper、无沙箱 Chromium 包装脚本、Lovart 客户端 |
| `tools/ref_analyze.py` | 拉片 |
| `tools/edl_check.py` | 镜头表检查 |
| `tools/vo.py` | 临时配音和逐字校对 |
| `tools/sfx.py` | 合成音效 |
| `tools/jm.py` | 即梦生成和积分账本，提示词里的 `@资产名` 自动换成节点引用 |
| `tools/animatic_example.py`、`tools/build_cut_example.py` | 动态分镜和剪辑脚本的范例（路径还是 CoolFly 项目的，照着改） |
| `higgsfield-motion` skill | `music_window.py`（测音乐结构和节奏点）；`render_audio.mjs` + `score.html`（代码合成配乐，运行时设 `HFT_BROWSER=/tmp/studio-tools/chrome`）；动态设计规范 |
| `higgsfield-timed-prompts` skill | 写带时间码的视频提示词 |
| `asset-discovery` skill | 检索免版权素材（Openverse、Mixkit 可用） |
| `jimeng-canvas`、`lovart` skill | 两个生成平台的用法 |

## 六、踩过的坑（每条都让 CoolFly 项目多返工了一轮）
1. **短片段拼接加后期特效显得假。** 应该一次生成一场戏，运镜写在提示词里。
2. **素材不够时反复切同一段画面。** 47 刀只用了 17 段素材，用户说"大量的重复镜头"。现在由 edl_check 拦截。
3. **用现成素材拼片子。** 节奏能做出来，但人物、场景、方向、光线对不上。Claude 靠缩略图判断不了镜头之间的衔接。**衔接要在生成时设计，不能靠事后拼。**
4. **跳过资产这一步直接画分镜。** 结果操纵杆一会儿在左一会儿在右，左手去握右侧的杆，衣服照搬了别的参考图，影子画成了客机的形状。**资产必须做齐、逐个确认。**
5. **AI 音乐不按时间走。** 先选定音乐，再按音乐的真实节奏点剪。
6. **对话太长时早期约定会被遗忘。** 每次开工都从这份规则和 HANDOFF.md 开始。对话太长时，先更新 HANDOFF.md，再开新窗口。
7. **用户在 CoolFly 项目里还指出过这些问题：**
   - 道具凭空出现；
   - 动作没有意义（例如对着镜头吹气）；
   - 产品发光；
   - 不合理的场景调度，例如飞行器从封闭的房间里飞出去；
   - logo 压在人头上；
   - 整屏纯色结尾卡和画面不搭。
