# 品牌图片物料

## 流程（每步都有用户确认关口）
1. **需求：** 用途、投放渠道和尺寸（例如 9:16 竖版、1:1、3:4 小红书、横版官网 banner）、数量、截止时间。文案要由用户提供或确认，不自己编 slogan。
2. **方向：** 出 2–3 个视觉方向。每个附一张参考情绪板（参考图、色彩、字体气质），说明各自的好处。✅ **用户选方向。**
3. **资产：** 用已确认的人物、产品、场景资产（见 ASSETS.md）。缺的资产先按 brand-video skill 第 1 步做好并确认。
4. **出稿和自查：** 先出小样，自查以下几项再给用户：
   - 文字有没有错字；
   - logo 有没有变形、比例和留白对不对；
   - 品牌色对不对；
   - 人手、人脸、产品结构有没有错；
   - 有没有混进别的品牌元素。
   - ✅ **用户确认。**
5. **定稿：** 出高清版和各尺寸延展，按命名规范存进项目目录，登记进 ASSETS.md，commit 并 push。

## 工具怎么选
| 需求 | 工具 |
|---|---|
| 有排版、有文字的设计稿：海报、KV、活动图 | **Lovart**（见 lovart skill） |
| 写实的人物、产品、场景画面 | **即梦 Seedream**（见 jimeng-canvas skill，`jm.py img`，引用资产用 `@名字`） |
| 文字必须百分之百准确：价格、参数、小字、多语言 | 画面用上面两种工具出，文字用代码排版叠上去（HTML/CSS 渲染，或用 Pillow），不要指望生成模型写对字 |
| 抠图、改尺寸、批量导出 | ffmpeg、Pillow |

## 规则
- 品牌色、字体、logo 用法、禁忌都以 BRAND.md 为准。
- 生成的文字（尤其是中文）经常出错，交付前必须逐字核对。
- 每张交付图都记下来源：工具、提示词或节点 ID，方便以后复刻或修改。
