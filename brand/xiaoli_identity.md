# 小丽 · 外形锁定（唯一标准）

- **唯一标准：** 用户新建画布里的原型参考图（Lovart 项目 `2ujk8uexd7gg`，用户上传图 `https://a.lovart.ai/artifacts/user/2wEl70ukql2RfHJ6.png`，本地副本 `brand/xiaoli_prototype_sheet.png`，2560×1440 角色设定板）。
- 旧画布「小丽」（`ot6jDEQsAo`）里的图有很多错误形象，**全部不用、不当参考**。
- 规则：样子固定，打扮可以按场景换。换装时下面「不能变」的部分照旧。
- 生成时每次都把原型图作为参考附上（`--attachments` 上面的地址），并把下面的锁定描述原样放进提示词。

## 不能变（样子）
| 部位 | 标准（色值取自原型的 COLOR PALETTE） |
|---|---|
| 风格、材质 | 3D 潮玩质感（哑光软胶 / 搪胶），6 岁 Q 版，大头，头身比约 1:2，身高标尺 105 cm |
| 脸 | 圆脸，肤色 `#FFE1D4`，淡粉腮红 |
| 眼睛 | 大而圆的深棕色眼睛 `#5A3A34`，有高光；细弯眉；鼻子是一个小点；小嘴 |
| 头发 | 黑发 `#2B1F1F`；**齐刘海**；**头顶正中一个高发髻**（只有一个）；耳朵两侧各一个由麻花辫盘成的小发环，辫尾垂到肩前 |
| 发饰 | 两侧发环上各一朵**黄色小花** `#FFD64D` 配绿叶；**头顶发髻右前侧一枚金色圆形发饰** `#D4AF37`，图案就是公司圆形标 |
| 耳饰 | 金色小环 + 珍珠水滴耳坠 |
| 手 | 五根手指，短圆的小手 |

## 标准打扮（可以按场景换）
| 部位 | 标准 |
|---|---|
| 裙子 | 珊瑚红 `#E35D5A` 中式连衣裙，及小腿，宽松直筒，一侧开衩 |
| 领口、袖口 | 白色毛绒立领、白色毛绒袖口（**裙摆没有毛边**） |
| 盘扣 | 胸前一枚白色盘扣 |
| 刺绣 | 裙身前下方粉色荷花 `#FFB7C5` 配绿色荷叶 `#7FA05A`，另有浅色线描暗纹 |
| 鞋 | 红色 `#C83C3A` 搭扣玛丽珍鞋，鞋面白色小蝴蝶结；**不穿袜子、不穿靴子** |

## 之前出过的错（自查时逐条对）
- 头顶画成两个大发髻（应是一个高发髻 + 两侧辫子发环）。
- 裙摆加白毛边；穿毛绒靴、白袜子。
- 金色圆形发饰画成别的图案，或者抛出去了头上还留着一枚。
- 脸变成大人、发黄。
