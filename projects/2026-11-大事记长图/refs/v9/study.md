# 参考研究：「两会新观察｜"人工智能+"赋能千行百业」（用户 2026-11-07 提供，ref_10–13）

用户要求：**风格和形式完全照这份参考做**，主题和内容换成丽尚国潮 2026 大事记。

## 两种产品形态
1. **一条长图**（ref_10，展示时切成三栏，实际是一整条）：从上到下按行业分段（制造 → 农业 → 医疗 → 交通 → 文旅 → 城市 → 科研 → 能源），每段一个大场景，最后一块是总结文字。
2. **单张海报**（ref_11–13，约 1:3）：每个行业一张。上面约 2/3 是这一段的插画（同一套画，重新裁切），下面压着两个**巨大的白色枯笔书法字**（农业、医疗、文旅），书法字中间竖排一行粗宋标题（系列名）和一行小字副标题。

## 画风
- **2D 商业插画**（新闻媒体常用的国潮科技插画）：清晰线稿，物体边缘有一圈**浅色高光描边**；柔和渐变上色；细腻**颗粒噪点**质感。
- **科技细节**：漂浮的发光小光点（白点带光晕）、细直光线、若隐若现的电路纹路和二进制字符、半透明发光数据面板（青色描边）。
- **人物**半写实，比例正常，表情自然。
- **放大核心**：主体很大、贴近镜头、常被画面边缘裁掉一部分（机械臂、汽车、无人机、手术机器人）；背景大面积平滑渐变，很空。

## 板块和过渡
- 每段一个主色：制造 = 天蓝，农业 = 草绿，医疗 = 浅蓝，文旅 = 淡紫到青绿……**相邻两段之间底色直接渐变过去**，没有分割线。
- 过渡靠"跨界元素"：前景的叶子、管道、光线、云、二进制字符从上一段伸进下一段；下一段的主体从渐变里浮出来。
- 场景之间、场景内部都留出安静的渐变区放文字。

## 文字
- 正文是**居中的粗宋体**，短句断行，深藏青色或白色；有时放在半透明白色面板上，压在插画一角。
- 海报的书法字是**白色、枯笔、飞白**，叠在插画下部；竖排标题是粗宋。
