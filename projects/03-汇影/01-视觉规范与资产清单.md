## 一、本集要讲清楚的事

方案原文：
> 汇，是城市的光影汇聚，是不同行业的人的身影汇聚。
> 影，是凌晨市场里整理货架的手，是酒店里抛起床单的弧线，是超市里摆正商品的专注，是城际酒店前台被感谢时的微笑。
> 三座城的产业光影，汇成一群人的尊严与幸福。

一句话：**用一天的光，串起三座城、八种劳动者的手和脸，最后汇成万家灯火。**

结构上的核心设计：**按一天的时间推进**。从凌晨的批发市场开始，经过白天的酒店和超市，到黄昏的黄河窗景，再到夜晚的万家灯火。观众不需要认识任何一个人物，光线的变化本身就是叙事线。这也让四集的"四色"有了落点：本集从冷到暖，最后落在暖金的灯火上。

## 二、视觉规范卡

| 项目 | 规范 |
|---|---|
| 片名 / 时长 | 丽尚潮声·第三集《汇影》，约 2 分钟 |
| 画幅 | **【待确认】** 建议与第一集保持一致。如果第一集还没定，建议 16:9（宽银幕 2.39:1 更有电影感，但竖屏切条时损失大） |
| 质感 | 真人实拍纪录电影质感。观察式镜头、偷拍感，人物不看镜头；35mm 胶片颗粒，自然肤色，不磨皮 |
| 参考 | 香港旅游局"城市诗意"（观察镜头）、香港美心与亚朵"七年如一日"（劳动者的尊严感）、《我的兰州》（西北城市质感） |
| 光线基调 | **每个镜头都有一个看得见的实际光源**：市场的裸灯泡、酒店的窗光、超市的顶灯、黄河的落日、夜晚的街灯。不用平光，不用棚拍光 |
| 色彩走向 | 00:00 凌晨冷蓝 → 00:20 批发市场的钨丝灯暖黄（冷暖对比）→ 白天中性偏暖 → 黄昏黄河暖金 → 夜晚万家灯火暖金 + 水面深蓝 |
| 景别原则 | 以特写和中近景为主：手、侧脸、背影、剪影。正脸只留给情绪重点（前台被感谢时的微笑）。远景只用在开头的三城和结尾的拉高 |
| 镜头运动 | 缓慢、克制：轻微手持呼吸感、缓慢横移、缓慢推近。结尾一个持续的上升镜头 |
| 系列母题 | **水**：每段结束在一个会反光的表面上（玻璃柜台、水盆、酒店窗户、黄河水面），用倒影转场，最后所有倒影汇入江河 |
| 固定说法 | 每条提示词原样重复：`真人实拍纪录电影质感，35mm 胶片颗粒，自然光与实际光源，人物不看镜头，不磨皮，不要广告感` |
| 禁止项 | 摆拍式微笑看镜头、商业广告的过度打光、HDR 硬边、网红脸、过度饱和、画面里出现可读的文字和品牌（丽尚 logo 只在片尾，后期合成） |

## 四、资产清单

### A. 人物（8 个，没有贯穿全片的主角）

露脸的人物才需要做完整的人物资产板；只拍手或背影的，做服装和手部参考就够。

| H05 | 亚欧超市理货员，20 多岁 | 手 + 专注的侧脸 | 人物资产板、**超市制服【需素材】** |
